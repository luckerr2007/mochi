- **GitHub 仓库搭建**：brew 安装 gh（`HOMEBREW_NO_AUTO_UPDATE=1`，默认自更新极慢），
  设备码流程登录 **luckerr2007**；公开仓库 **https://github.com/luckerr2007/mochi**，

- **踩坑 ①（workflow scope）**：推送含 `.github/workflows/` 的提交需要 token 有 `workflow`
  权限，初次登录默认只有 `repo` → `gh auth refresh --hostname github.com --scopes workflow` 补授权。
- **踩坑 ②（终端没走系统代理）**：`api.github.com` 直连通、`github.com` 主站直连超时
  （设备码接口在主站），gh 表现为"一直拿不到一次性代码"。本机系统代理
  `scutil --proxy` → 127.0.0.1:50917（HTTP/HTTPS/SOCKS），终端命令需显式
  `HTTPS_PROXY=http://127.0.0.1:50917`（端口随代理App重启会变）。git push 也一样要带。
- **踩坑 ③（pkill 自杀）**：`pkill -f 'gh auth refresh'` 的复合命令里自身命令行就含该
  字符串，会把所在 shell 一起杀掉——清理进程别和同名命令写在一条里。
- 待办衔接：**npm v1.1.0 已发布**（`npm view mochi-island-ui version` = 1.1.0，绕 2FA 的

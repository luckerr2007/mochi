# 尺寸标准

组件大小不统一，界面就会显得"拼出来的"。这份表是唯一的尺寸来源，**组件不允许自己拍数值**。

## 控件高度

| 令牌 | 值 | 用在哪 |
| --- | --- | --- |
| `--mochi-control-sm` | `32px` | 小按钮、分页、密集工具栏 |
| `--mochi-control-md` | `40px` | **默认**：按钮、输入框、选择器 |
| `--mochi-control-lg` | `48px` | 主行动按钮、大屏 |

字号随高度走：`sm → 13px`、`md → 15px`、`lg → 18px`。

**硬性规则**：同一行里的控件必须等高。`MochiButton size="md"`、`MochiInput`、`MochiSelect`
放在一起时，三者都是 40px——这是 `FieldShell` 的 `min-height` 和按钮的 `height` 共同保证的。

## 不跟控件走的四个刻度

有些东西不是"输入框"，强行套 32/40/48 反而难看：

| 元素 | 尺寸 | 理由 |
| --- | --- | --- |
| Checkbox / Radio | `20px` 固定 | 是"标记"不是"框"，跟着按钮变大只会显得笨 |
| Switch 轨道 | `44 × 26` 固定 | 开关需要足够的行程，和高度无关 |
| Avatar | `28 / 40 / 56` | 独立人像刻度（sm/md/lg） |
| Tag | 高度自适应（约 26） | 是标签不是控件 |

## 圆角

| 场景 | 令牌 |
| --- | --- |
| 按钮、标签、开关、分页 | `--mochi-radius-full` |
| 输入框、面板、卡片、气泡 | `--mochi-radius-md` / `lg` |
| 勾选框、色块 | `--mochi-radius-xs` |

## 间距

一切间距取 `--mochi-space-unit`（4px）的整数倍：
`1=4` `2=8` `3=12` `4=16` `6=24` `8=32`。
组件内部的"呼吸"用 8/12，组件之间的分组用 16，分区之间用 24/32。

## 动效标准

每个可交互元素必须有三种状态，缺一不可：

| 状态 | 处理 | 令牌 |
| --- | --- | --- |
| 静止 | 有台阶（`0 2px 0` 或 `0 4px 0`） | `--mochi-shadow-press` |
| 悬停 | 抬起 1px，台阶同步长 1px | `--mochi-duration-fast` |
| 按下 | 位移 = 台阶高度，台阶归零，**时长压到 90ms** | `--mochi-duration-press` |

曲线分工：

| 曲线 | 用途 |
| --- | --- |
| `--mochi-spring` | 小元素位移：按钮、滑块、星星 |
| `--mochi-spring-soft` | 大面积：对话框、抽屉、弹层 |
| `--mochi-ease-out` | 颜色、透明度淡入 |
| `--mochi-ease-in` | **离场**，比入场快一档 |

三条纪律：

1. 入场慢、离场快——反了会像卡顿。
2. 按下比松手快——同一段位移，90ms 进、220ms 出。
3. 所有动画都要有 `prefers-reduced-motion` 降级：去掉位移与过渡，**保留颜色/状态反馈**。
